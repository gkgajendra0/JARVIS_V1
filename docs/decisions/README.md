# Architecture Decision Records

This directory contains short Architecture Decision Records (ADRs) for major accepted technology or architecture choices.

ADRs are supporting evidence, not a second planning authority. `docs/PRODUCT.md` owns the permanent product definition and `docs/CURRENT_PLAN.md` owns the active product slice.

Create an ADR only when a decision is important enough that future work needs to know why it was made.

Use the form:

- Context
- Decision
- Alternatives considered
- Why this choice
- Consequences and tradeoffs
- Replacement boundary
- Conditions that should trigger reconsideration

Do not create ADRs for routine implementation details, temporary experiments, bugs, or minor refactors. Git history remains the chronological archive.
