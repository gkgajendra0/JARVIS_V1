# JARVIS V1 Current Plan

## Active Step

**Step 0 — Repository Bootstrap**

Build and validate only the clean Python application foundation:

- a modern `src` package layout;
- a minimal application composition root;
- environment-based configuration;
- standard-library console logging;
- focused lifecycle and import-safety tests.

Step 0 contains no voice conversation, wake word, memory, capabilities,
authority system, provider SDK, model initialization, microphone access, or
network access.

## Completion Gate

Step 0 is ready for human review when focused tests, import/compile checks, and
the basic startup/shutdown command pass. Step 1 is not authorized by Step 0
completion.
