# JARVIS V1

JARVIS V1 is a clean implementation of the personal JARVIS assistant.

The previous JARVIS project is treated as engineering reference, not a runtime
dependency.

Current active work: **Step 0 — repository bootstrap**.

Development authority:

- [Product definition](docs/PRODUCT.md)
- [Current plan](docs/CURRENT_PLAN.md)

## Run

With the package installed, or with `src` on `PYTHONPATH`:

```powershell
python -m jarvis
```

## Test

```powershell
python -m pytest
```
