# JARVIS V1

JARVIS V1 is a clean implementation of a personal, voice-first JARVIS assistant.

The previous `gkgajendra0/JARVIS` repository is engineering reference only. JARVIS V1 does not import it or depend on it at runtime.

Steps 1, 2, 2.5, and 3 are accepted. Step 4 is closed as a **bounded accepted memory/context foundation through Phase 4.5C**; automatic semantic conversational memory release remains deliberately deferred rather than weakening the safety boundary.

Step 5 — Local/Offline Survival and Provider Resilience — is planned but **not started** and awaits explicit owner authorization.

See `docs/CURRENT_PLAN.md` for the operational state, `docs/CURRENT_ARCHITECTURE.md` for accepted architecture, and `docs/ROADMAP.md` for sequence.
